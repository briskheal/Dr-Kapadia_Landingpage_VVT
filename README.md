# Dr. Sumit Kapadia - Varicose Vein Landing Page

A high-converting, medically compliant landing page for Dr. Sumit Kapadia, specializing in varicose vein treatments in Gujarat.

## Features
- **Modern Healthcare UI**: Clean, minimalist design with professional aesthetics.
- **Brand Integrated**: Uses original brand colors (#CE176B Magenta and #014A81 Navy).
- **Medically Compliant**: Follows strict guidelines (No testimonials, no before/after, factual tone).
- **Mobile First**: Optimized for small screens with a sticky CTA.
- **High Readability**: Premium typography (Montserrat & Poppins).

## Project Structure
- `index.html`: Main landing page structure and styling.
- `clinic.png`: Custom generated high-end clinic interior visual.
- `package.json`: Simple setup for local preview.

## How to Run Locally
1. Ensure you have Node.js installed.
2. Run `npm start` to view the page on a local server.

## Design Decisions
- **Tone**: Empathetic and reassuring, avoiding overpromising language.
- **Layout**: Clear sections with smooth scroll flow.
- **CTAs**: Focused on "Book Consultation" and "Call Now" for high conversion.
